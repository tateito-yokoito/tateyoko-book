# 販売・割引・ギフト仕様

更新日: 2026-08-23

## 価格と購入導線

- 縦糸横糸ブック本体は税込49,800円。国内送料を含む。
- 本人利用は、最初の3つの問いを無料で利用してから購入できる。
- 購入確認画面で通常価格、割引額、ギフトパッケージ代、支払合計を表示する。
- カード情報はStripe Checkoutだけで取り扱う。
- 金額変更時は既存のStripe Productを維持し、新しいStripe Priceを作成する。
- 0円になる注文も注文台帳に記録し、Stripeの `no_payment_required` を完了として扱う。

## 割引

- 1注文につき1コード。併用不可。
- 割引対象は本体だけで、ギフトパッケージには適用しない。
- 返金してもコードを自動復活させない。
- クラウドファンディング: 支援者ごとの個別コード、メール指定なし、原則1回。
- 広告: 共通コード、利用期間・全体上限・1アカウント1回を設定可能。
- 代理店: 代理店ごとの共通コード、複数回利用と販売元集計に対応。手数料精算は別途設計する。

## ギフト

- 購入者が先に支払い、受取人は専用リンクまたはパッケージのコードから受け取る。
- ギフトパッケージは税込3,000円を初期値とし、購入時は推奨オンにする。
- パッケージにはコンセプトブック、使い方、贈る言葉、受取用QR・コードを含める。
- 受取人には価格、割引、決済、返金、「無料体験」という表現を見せない。
- 受取人には「最初の三つの問い」と案内し、その後に続けるか休むかを選べるようにする。
- 受取操作はログイン後の明示ボタンで確定し、リンクを開いただけではアカウントへ紐づけない。

## 40日保証

- パッケージあり: 配達完了日から40日。
- パッケージなし: 購入完了日から40日。
- 4つ目の問いに回答する前、かつ製本開始前であれば、本体の実支払額の返金を相談できる。
- パッケージ製作前は全額取消可能。発送後のパッケージ代は返金対象外。
- 40日経過後も利用権は残り、保証だけが終了する。
- 購入者には期限の約10日前を目安に案内し、受取人には保証や返金の情報を表示しない。

## 管理権限

- 注文・コード・ギフト配送・保証状態は「販売」タブで閲覧する。
- 配送状況の更新は通常の管理者が行える。
- 価格、キャンペーン、コードの変更はownerだけが行える。
- 変更時は再認証後の販売管理モードを使い、初期値は15分で自動終了する。
- 販売管理モードの時間は `commerce_settings.sales_mode_minutes` で変更できる。

## 記録の原則

- 会計履歴は `commerce_orders` に保持し、物語や受取人の状態と分離する。
- Webhookを支払完了の正とし、イベントIDで重複処理を防ぐ。
- 割引コード利用は予約・確定・解放・返金を別状態で記録する。
- ギフト購入者と物語の主体は別アカウントとして保持する。
