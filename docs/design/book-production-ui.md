# BOOK制作画面の共通デザイン

対象は購入後のBOOK利用者画面、質問回答、制作案内、語り、仕上げ、設定です。家族アプリ、公式HP、完成Webブックには適用しません。

## 正本

`src/book-production-tokens.css` の `--book-*` が色・書体・文字サイズの正本です。背景を調整するときは `--book-page`、主ボタンは `--book-primary` を変更します。個別画面に同じ色の16進値を追加しないでください。

| 役割 | 変数 | 現在値 |
| --- | --- | --- |
| ページ背景 | `--book-page` | `#f8f7f2` |
| カード・入力面 | `--book-surface` | `#fffefa` |
| 本文 | `--book-ink` | `#243b31` |
| 補助文字 | `--book-muted` | `#53665b` |
| 主操作 | `--book-primary` | `#284c40` |
| 境界線 | `--book-line` | `#c9cfc5` |

操作・説明・入力・通常の見出しは `--book-ui-font`（ゴシック）を使います。明朝は問いや章の主題など、作品として読ませる短い文言に限ります。通常本文とボタンは16px、補助文字は14pxを目安にし、入力欄はiPhoneで拡大されない16px以上にします。操作部は44px以上のタップ領域を確保します。

主ボタンは `.book-primary-action` の深緑の塗りと白文字、副操作は明るい面に深緑の文字と境界線、進捗などの装飾にアクセント色を使います。一つの画面で主ボタンを増やし過ぎないでください。画像上の白文字や録音中の状態色は、背景と状態を確認して個別に扱います。

## 運用

1. 新しいBOOK利用者画面は `.app-container--book-light` または `.book-user-light` の内側に置きます。
2. 新しい色は役割を決めてから正本へ追加します。旧画面互換の `src/book-user-light.css` にあるクラス名による上書きを、新規画面へ増やさないでください。
3. 回答の共通コンポーネントは `src/answer-input-ui.css` で `--book-*` を参照し、BOOK以外では従来色へフォールバックします。
4. 変更時は隔離TESTの `?book_ui_review=index` で制作ホーム、回答方法、文章、音声、回答確認、語り、仕上げ、設定をスマートフォン幅で比較します。家族アプリと完成Webブックに波及していないことも確認します。
