# 運営管理画面

## アクセス

本番環境では、次のURLから開きます。

`https://www.tateito-yokoito.jp/?admin=1`

管理者として登録されていないアカウントは、ログイン後もデータを閲覧できません。画面に表示される「ユーザーID」を使って、最初の管理者だけをSupabase SQL Editorから登録します。

```sql
insert into public.admin_users (user_id, role)
values ('画面に表示されたユーザーID', 'owner')
on conflict (user_id) do update
set role = 'owner', is_active = true;
```

登録後に管理画面を再読み込みします。

管理者ログインは、次のどちらの方法でも行えます。

- メールアドレスとパスワード
- メールで届く認証リンク

初めてパスワードを使う場合や忘れた場合は、管理者ログイン画面の「パスワードを設定・再設定」から設定メールを送信します。メール内のリンクを開き、新しいパスワードを登録してください。

## 権限

- `owner`: 管理者の追加・変更を含む最上位権限として予約
- `operator`: 日常運用担当者向けとして予約
- `viewer`: 閲覧専用として予約

初期版の管理画面は、すべての権限で閲覧専用です。データの変更、削除、返金、招待の再送などは行いません。

## 確認できる内容

- 要対応: 招待メール失敗、文章生成失敗、決済途中、長期間止まっている初期登録
- 物語: 無料体験・購入状況、進捗、最終活動、語り・共有・サポーターの詳細
- アカウント: 氏名、メールアドレス、所有・お手伝い中の物語数、最終ログイン
- 決済: 決済状態、金額、Stripe Checkout ID、更新日時
- 語りを見る: 利用者向けの閲覧画面と同じ表示で、問い・原稿・写真を確認
- 本に仕上げる: 利用者向けの本づくり画面を閲覧専用で確認

管理画面へのアクセスは `admin_audit_logs` に記録されます。

「語りを見る」と「本に仕上げる」は、管理画面専用に複製した画面ではありません。利用者画面と同じReactコンポーネントを再利用し、管理画面から開いた場合だけ編集・写真追加・収録変更を無効にします。利用者画面の表示を更新すると、管理者プレビューにも同じ変更が反映されます。

プロジェクト詳細には旧仕様の語り一覧を重ねて表示せず、「語りを見る」を唯一の閲覧導線とします。管理画面の物語名は敬称を付けず、登録済みの姓・名を表示します。
