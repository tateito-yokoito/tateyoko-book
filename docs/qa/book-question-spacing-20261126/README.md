# BOOK質問カード余白（TEST）

プレビュー： https://tateyoko-book-test-b6djwjp32-tateito-yokoito.vercel.app/?book_ui_review=question_sizes

採用候補のB案・質問文95％で確認。390×844の最長質問では、前版比でカード上端が185→161px（24px上）、カードと補足の間が14→28px、補足と操作の間が147pxのまま。短・標準・最長の3問とも操作まで一画面に収まる。

320×568では長い質問にスクロールが必要。カードと補足の間は28px、横はみ出しはなく、文字125％でも終了操作へ到達できる。画像は同じフォルダのJPEG。既存の回答・録音・保存処理は変更していない。
