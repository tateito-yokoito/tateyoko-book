# Webブック：読む／聴く連続体験（確認用・未公開）

## 承認済み一行プレイヤーの組み込み

音声・動画の操作部を `WebBookMediaControls.jsx` で共用。丸い44pxボタン、シーク、経過／総時間の一列とし、「声を聴く」の重複行は削除。`WebBookVideoPlayer.jsx` は再生前から16:9の枠を表示し、playsInline／独自の一行操作部を使用（ネイティブ操作部を重ねない）。動画と音声は相互に一時停止する。

音声DOMはWebBook直下で維持し、操作部だけをportalで個別語り／固定ミニプレイヤーへ移動する。同じ語りを開いているときは固定プレイヤーを非表示にし、他ページを読むときは固定側へ戻す。音声の読み直し・再生位置リセットは発生させない。連続再生が次の語りへ進んでも閲覧ページは変更しない。

主回答が動画で音声がすべて動画由来の場合、同じ内容の音声操作部を重ねない。ただし全体音声再生中の該当ページでは現在の音声操作を維持する。別に録った音声もある場合は音声操作を残す。既存の録音・動画・認可・DBは変更しない。

Chrome 390pxで個別音声・動画の44px高、動画枠の初期表示、自動再生なし、再生／一時停止／シーク、二重表示なしを確認。既存の単体・ブラウザ・全体連続再生テストも通過。本番デプロイは本項の実装作業には含めていない。

## 範囲

既存の生成り・深緑・TOP・テーマ・語りページを維持。新しいDB変更・migration・Storage加工・本番反映はない。既存の未公開Webブック実装に対するフロント中心の改訂。

## 一元的な順序

`src/lib/webBook.js` の `webBookStorySequence()` が唯一の作品順序を生成する。

はじまり → 今の私（最近の暮らし／日々の楽しみ）→ 既存9テーマ → 旧作品の分類不明な語り（存在時）→ おわり。

- 名前の声は除外し、TOPから独立再生。
- 回答・文章・音声・写真・動画がない項目は除外。
- テーマ内は保存された `sourceSequenceOrder`、なければ既存 `order`。既存公開作品の素材インデックスは変更しない。
- ID、種別、テーマ／質問情報、音声キュー、動画、前後ID、最終判定を同じentryに集約。
- 読む順序はこのsequence。音声再生順序は同sequenceの音声ありentryだけを抽出し、並べ替えない。
- おわりなしの場合は最後の実在する語りを最終とする。空の章は作らない。
- 旧作品の分類不明な語りは失わず保存順で残す（テーマを推測しない）。

## 音声の二層

1. 一つの語り：元音声＋語り足しを既存ファイルの再生キューとして連続再生。単一の再生位置バー／合計時間。統合済み本文は一つ。
2. 一冊：TOPで明示的に開始した後だけ、語り終了を受けて次entryを開始。個別の「声を聴く」は単発のまま。`startContinuous(entry)` は途中entryからも開始できる内部構造。

音声DOM要素を語り間でも再利用する。読みページの移動は再生stateを変更しない。音声が進んでも読むページは自動遷移しない。ミニプレイヤーのタイトルから現在の語りを開ける。最終音声で停止しループしない。

元データの物理結合や上書きは行わない。各ファイルの署名URLは必要時に既存resolverから取得する。素材に総時間が未記録の場合、未読込分まで含む不正確な総時間は表示しない。

## 動画

保存済みの抽出音声が `item.audio` にある場合は、その音声を既存キューの一部として再生する。動画そのものを不可視のバックグラウンド再生にはしない。動画しかないentryは読む順序には残し、音声連続再生のみ除外する。「はじまりを見る／おわりを見る」等の個別動画再生を維持。

## UI

- 語り末尾に「次の語り」、章が変わる場合は「次の章」と実テーマ名・質問名。前の語りは控えめな補助。
- TOPに「声で、この人生を辿る」。モード選択なし。
- 固定ミニプレイヤー：現在の章・質問、現在／合計時間、シーク、前／一時停止・再生／次、閉じる。
- 本文末尾がプレイヤーに隠れない余白とsafe-areaを確保。
- 「また、この人生に逢いにくる。」は最終の語りページだけ。TOP・途中ページには表示しない。

## 確認と制約

- Chrome 390px：通常／1回／複数回の語り足し、前後・テーマ間移動、TOP連続再生、自動次音声、読みページ維持、一時停止／再開、同一音声DOM、再生位置維持、最終停止、おわり有無、最終コピー一回、横溢れなし。
- 音声の各境界は実HTMLMediaElementの末尾シークで検証。サンプル音声による確認であり顧客データは使わない。
- 自動再生が拒否されたら、再生ボタンの明示操作内で直接playを呼ぶ復帰経路を用意。
- Safari/WebKit実行環境がこのマシンに未導入のため、iPhone Safari実機は未確認。画面ロック／バックグラウンド継続は保証しない。署名URL取得や通信によりファイル境界に短い待ちが生じ得る（物理結合の完全なgapless再生ではない）。
- 同一Webブックのマウント中のみ再生位置を保持。リロード後の再開保存は対象外。
- 既存作品／購入／共有認可は変更しない。前の実装レポートにある公開・作品更新の未決事項を今回の改修で解除しない。

本番反映はプレビュー承認後。Safari実機・本番素材／署名URLでの再生は公開前確認として残す。
