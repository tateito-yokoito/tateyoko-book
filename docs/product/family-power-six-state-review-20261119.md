## 表示する実データの境界

| 状態 | 家族ホーム | 人物ページ・人生 |
| --- | --- | --- |
| A | 家族・BOOK・思い出を空状態で表示。家族登録を主操作にする | 人物情報だけを表示。語りとBOOKは空状態 |
| B | 登録した人物を表示。BOOKや思い出の完成データは置かない | 既存の語りを表示。完成したBOOKは置かない |
| C | 完成・制作中・未開始の作品がある例。思い出カードもある | 完成Webブックとテーマ別の語りを表示 |

これは状態を比較する**架空のサンプル**。A・Bに完成作品を仮表示しない。B人物ページの「記録あり・BOOK未完成」は、購入済み制作中と無料記録のみを区別する表示条件がまだ必要。Ver.2.0は実装済みとして表示しない。

## 素材とデザイン

- ヒーロー・架空人物の肖像・3種類の表紙は、画像生成スキルで今回作成した**レビュー専用の仮素材**。生成画像を `public/previews/family-power-assets/` に保存した。実在の顧客や作品ではない。アイコンはモック内のSVG。
- 生成プロンプト：ヒーローは「日本の家族史向け、暖かな朝焼け、青い山並みと緑の田園、水彩調、文字なし」。肖像は「架空の高齢の日本人男性、自然光の編集写真、文字なし」。表紙は「青い山・桃色の丘・セピアの家族の3面、和の水彩調、文字なし」。いずれも組み込み画像生成ツールを使用した。
- 承認済み合成画像は左端の**比較参照だけ**に使用し、ヒーロー・肖像・表紙として切り出していない。仮素材を本番に採用する場合は、代表者の確認と実素材への差し替え判断が必要。
- 生成り、深緑、オリーブ、角丸、柔らかな影、写真の密度、アイコン付きナビゲーションを共通化。C状態は承認済みVer1.0の画面構成へ近づけた。

## BOOK制作モードへの接続方針

1. 家族の場所を通常の入口にし、人物ページから対象人物と制作中作品を選ぶ。**人物が存在するだけでBOOK作品を作らない。** 現行 `ensureUserFoundation` はログイン時に初期作品を確保するため、この境界は実装前に変更が必要。
2. 購入・権利付与は既存の `PurchaseSelectionEntry` / `CommerceV2Purchase` と既存の作品・権限判定を使用する。家族ホームから未購入者をBOOK販売へ無条件に送らない。制作可能な人物・作品だけ既存の `ApprovedHome` へ入れる。
3. 制作開始前後の接続部分（人物名、作品の状態、戻り先）に生成り・深緑の共通ヘッダー／遷移表示を適用する案とする。質問回答、録音、AI整形、写真、仕上げ、公開の内部フローは今回の対象外。濃紺画面への切り替えは、最初に**制作モードへ入ったことが分かる入口と戻り先**を設けて緩和する。制作画面全体の配色変更は別レビューで判断する。
4. 完成後は人物ページに完成Webブックを表示する。元回答からテーマ別語りを示す場合も、既存の回答権限を確認し、本人限定の記録を家族一覧へ出さない。

## 実装時の変更範囲と主なリスク

| 範囲 | 最小変更の方向 | リスク・先に決める条件 |
| --- | --- | --- |
| 初期基盤 `src/App.jsx` | 家族／人物作成とBOOK作品作成を分離 | 既存購入済み作品との紐付け・ログイン再開を壊さないこと |
| 入口 `src/main.jsx`、家族画面 | 状態別ホームと人物ページを接続 | 現行の家族接続はTEST限定。権限と本番提供範囲を先に確定すること |
| BOOK接続 `src/home/ApprovedHome.jsx` | 対象作品を渡して既存制作ホームを開く／家族へ戻る | 本人・購入者・代理制作者で作品選択と権限が異なること |
| 人物の語り一覧 | 完成BOOKの元回答と完成後の追加語りを人物に関連付ける | 非公開語りの存在・件数・メディア漏出。完成済みBOOKを自動更新しないこと |
| 購入入口 | 既存購入画面を人物・作品へ接続 | 一般購入ゲートの現状を維持。購入権利と対象人物の対応を検証すること |
| デザイン接続 | 共通ヘッダー・戻り先・状態表示を限定適用 | BOOK制作内部を一括改修せず、旧画面との切替を実機で確認すること |

本資料は画面状態と接続方針のレビュー用。保存・権限・購入・公開の動作確認結果を示すものではない。
