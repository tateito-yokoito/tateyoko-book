# 旧利用動線マスター（履歴資料）

[`user-flow-master.xlsx`](./user-flow-master.xlsx) は過去の検討・変更履歴を保持する資料です。現在の確定仕様の正本は親ディレクトリの [product-spec.md](../product-spec.md)、[user-flows.md](../user-flows.md)、[design-system.md](../design-system.md)、[acceptance-tests.md](../acceptance-tests.md) です。

旧Excelには「Supporterは原則すべての語りにアクセスできる」という旧記載があります。現在の確定仕様は「お手伝い中の人は非公開の語り・保存ファイルにアクセスできない」です。旧Excelの記載を実装判断の根拠にしないでください。旧価格や旧購入経路など、未移管・矛盾のある箇所は正本の「要確認・実装差分」に記録します。

既存Excelのシートと履歴は変更せず保存します。今後の仕様変更は該当するMarkdown正本をコードと同じレビュー単位で更新します。Excelを再び正本とする場合は、明示的な合意と差分整理が必要です。
