# 人物ページ4タブ・第1段階の実装記録

PCでもスマホ幅で見る入口：`https://tateyoko-book-test-hei8kzcdj-tateito-yokoito.vercel.app/family-place-mobile.html`（実アプリ、メール認証が必要）。人物ページの表示部品だけをすぐ確認する場合は `https://tateyoko-book-test-hei8kzcdj-tateito-yokoito.vercel.app/family-person-review.html`（保存しないレビュー用データ）。

## 変更

実際の `FamilyPlaceApp` の人物ページを **年輪｜本棚｜思い出｜年表** に変更。年輪には人物の既存無料3問の保存済み回答と回答入口を表示する。本棚は既存 `list_voice_library()` で閲覧権限を認められた公開作品を人物IDで絞り、既存 `/?voice=公開ID` に接続する。公開Webブック本体、印刷QR、購入・制作処理は変更しない。複数の公開版は新しい順に表示する。[スマートフォン幅の比較画像](design-references/family-person-four-tabs-stage1-20261122.png)。

隔離TESTだけに読み取り専用RPC `list_family_place_person_books(uuid)` を適用（migration `20261122045654`）。既存の本棚RPCの返却行と `book_projects.subject_person_id` を結ぶ。匿名実行は不可で、既存の認証済み本棚権限を拡張しない。既存データは変更しない。本番DBへの適用は別途必要。

## 次段階へ残す仕様衝突

1. 現行の無料人物記録は `family_free_stories`（人物・3問）で、BOOK回答は `answers`（作品・質問番号）。現状は別データであり、原本統合は未実装。
2. 現行無料人物3問は `CHILDHOOD_TRIAL_QUESTIONS` を暫定利用。BOOKの問いとの正式な対応と質問文は未確定。どの問いを同一原本とするか、オーナー判断が必要。
3. 現行無料人物記録は本人の初期値が `private`。新仕様の家族共有初期値と異なる。さらに現行の家族共有RLSは家族所有者中心で、共同管理者・お手伝いの新しい鍵権限を表現しない。安全な権限移行まで旧記録の可視性を自動拡大しない。
4. 現行BOOK完成は作品別回答を編集不可とし、公開版の固定スナップショットを作る。新仕様では年輪原本のみ完成後も編集可能にする必要がある。完成済みの収録内容と公開QRの互換性を維持しながら接続する。
