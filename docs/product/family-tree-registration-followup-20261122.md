# 家系図・人物登録の追補（隔離TEST）

対象: `codex/book-answer-shared-design`。本番環境は未変更。

## 変更

- 「家族／自分」の選択欄を削除。自分が未登録の通常登録では、登録した人物を自分とする。
- 現在の家系図に関係がない登録済み人物がいる場合だけ、名前を選ぶメニューを表示。新しい人物を重複作成せず関係だけを保存できる。
- 姓名の各ふりがなを既存の人物行に追加。既存登録RPCは残し、ふりがな付きの新RPCを追加。
- 性別欄の「任意」を削除。未登録の選択肢は維持。
- プロフィール写真に円形ガイド、ドラッグ、ピンチ・スライダーによる拡大を追加。保存前に512px四方へ切り出す。
- 家系図を添付参考画像に寄せ、丸い人物像、名前と関係名、親子・配偶者の線、金色の輪と白い台紙で中心人物を区別。追加操作は下にまとめた。
