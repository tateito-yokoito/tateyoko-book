# 家系図 P0 隔離TEST結果（2026-11-22）

対象: `codex/book-answer-shared-design`。本番環境・本番DBは変更していない。

## 実装

- 既存 `persons` をそのまま利用し、親子・配偶者の関係だけを `family_person_relations` に保存する。
- 家族ホームと通常の人物登録から家系図へ接続。登録時の人物と関係は1トランザクションで保存する。
- スマートフォンでは中心人物の親・配偶者・子を表示し、人物を選んで中心を移動できる。自分へ戻る、人物ページへ進む、関係の変更・解除ができる。
- 写真を優先し、未登録時は年齢層と任意の性別に応じた共通イラストアバターを表示する。
