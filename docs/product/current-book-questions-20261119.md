# 現行アプリの質問一覧（2026-11-19）

## 抽出基準

- 本番DBの有効なデフォルトセットは `tateito_yokoito_standard_v2`（version `v2`、set ID `87912e71-1bed-464a-a685-8e2cf231cc7a`）。`src/App.jsx` の `getDefaultQuestionSet` → `ensureUserQuestions` は、このセットの有効な `question_set_items` を `sequence_order` 順に作品へ複製する。
- 表示文は `question_text_snapshot` を優先し、なければ `questions.content` を使う。未回答の問いには公開済み `admin_question_copy` が上書きされ得るが、抽出日時の本番DBに公開済み上書きは **0件**。回答済み・スキップ済みの文は上書きしない。
- 既存作品は `book_projects.base_question_set_id` で固定される。旧 `koebook_standard_v1` を使う作品もあるが、本書の「現行デフォルト」には混ぜない。個別作品の管理者編集・カスタム文は作品ごとに異なる。
- 本書は質問の変更提案ではない。人物別の新しい無料3問も未確定で、下記の既存BOOK試用3問を自動的に採用する意味ではない。

## 表示順と分岐

1. 新規v2作品は「はじめの会話」3問から開始。本編はテーマ1～9、各テーマ内は内部順に進む。
2. 無料体験経路は専用3問を `onboarding_group='trial_experience'` で選ぶ。BOOK購入後に無料体験を本編へ組み込むかは、別の引き継ぎ処理・作品状態で決まる。
3. テーマ終了時の追加質問は**回答文の内容による自動分岐ではない**。利用者が任意で選ぶ。選ばなければ次のテーマへ進む。
4. 基本質問の回答・スキップ状態と作品の導入進捗で再開位置が決まる。現在のデフォルトセットの `question_set_items.meta_json` に回答内容を条件にした `branch_condition` はない。プロフィールの配偶者・子ども等の回答による、この9テーマ23問の自動出し分けもコード上では確認されない。
5. 旧版の作品、個別に追加・編集された問いは固定された作品側の `user_questions` が正本であり、本一覧と異なり得る。

参照：`src/App.jsx`（質問セット選択・配布・無料体験・追加質問RPC・進捗）、`src/lib/themeExtras.js`、`src/lib/journeyQuestionOrder.js`、`src/lib/questionCopy.js`、本番DBの `question_sets`・`question_set_items`・`admin_question_copy` の**質問定義のみ**。顧客回答は取得していない。
