# 公開済み回答UIのDB定義（参照用）

このフォルダは 2026-10-25〜28 に作成された回答・下書き・依頼機能のローカルSQLソースの参照コピーです。両環境には該当テーブルと関数が存在しますが、各SQLの全文と実環境の定義が完全に一致することまでは確認していません。ただし本番の `supabase_migrations.schema_migrations` に記録された番号は `20261028...` 系であり、これらの元ファイル名とは一致しません。

このSQLを `supabase/migrations/` に移して `supabase db push` しないでください。重複適用や意図しない置換を招きます。将来DBを変更する際は、実DB定義・適用履歴と照合してから新しい正規マイグレーションを作成し、本番適用は別途承認を得ます。この統合作業ではDBを変更していません。
