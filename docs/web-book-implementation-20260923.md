## 未完了・決定が必要

1. **完成後の更新**: 現行のbook_work_manifestsにはimmutable triggerがあり、Edgeも更新を409で拒否する。紙とWebを同じ確定作品とする現行原則と衝突するため、更新ボタンを偽装したり制限解除したりしていない。Webの明示的な新revisionを許可するか、紙も含め新作品とするかを決める必要がある。現在の差分検出は既存収録対象中心で、未選択の新規語りの追加検知までは未実装。
2. **顧客によるQR公開操作**: 新しい公開ボタン追加は安全レビューにより停止。顧客が既存link/code方式で公開できる範囲を明示確認するまで追加しない。非公開確認だけで公開はされない。
3. **確定後の顧客動画プレビュー**: 公開コピーの動画に対する顧客Storage RLSによって署名が拒否される可能性が残る。サービスロールへ迂回する変更も安全レビューで停止され、適用していない。顧客署名は現行RLSを維持。実環境の対象ごとの確認と、必要なら明示的な認可設計が必要。
4. **既存完成作品の冒頭3問**: 確定snapshotに含まれない場合、ライブデータから勝手に補わず非表示。既存作品の再確定／移行は別途承認が必要。
5. **QR入稿**: URLは既存public_idを再利用するためPremium追加で新作品を生成しない。QR配置コンポーネント／標準紙面確認は実装したが、実製本の入稿物に対する配置検証は未実施。公開前に最終入稿経路を確認する。
6. **実環境確認**: ローカルブラウザの確認用メディアでの再生。実顧客の署名URL／アクセス期限、iOS Safari、リモートTESTの認可マトリクス、実注文は未検証。本番投入前のRelease Gateとする。
