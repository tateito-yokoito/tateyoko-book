# tateyoko-book
tateyoko BOOK: a voice-to-book app for preserving life stories.

## 仕様の正本

確定仕様は [docs/product/product-spec.md](docs/product/product-spec.md)、[利用動線](docs/product/user-flows.md)、[デザイン・UI原則](docs/product/design-system.md)、[受け入れ条件](docs/product/acceptance-tests.md) を参照してください。従来のExcelと日付付き資料は履歴・参考資料です。

仕様変更を伴うコード変更では該当する正本も同じブランチで更新し、差分と検証結果をレビューに示します。main統合と本番反映は別途承認に従います。

## 現在の開発方針（固定仕様ではない）

1. 第1優先：HPからの本人購入・ギフトA・ギフトBのE2E。
2. 第2優先：無料3問から上記3経路への接続。

この順序は進行中の作業の優先順位です。商品・UXの確定仕様は上記の正本で管理し、優先順位が変わっても仕様変更とは扱いません。
